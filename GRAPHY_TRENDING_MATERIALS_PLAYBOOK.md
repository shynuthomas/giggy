# LearnTechGuru (Graphy) - Trending Study Materials Playbook

This playbook is tailored for your website:

`https://learntechguru.graphy.com/`

Use it to publish new, high-demand materials that students can purchase quickly.

## 1) Add a "Trending This Month" shelf on homepage

In your Graphy site builder/dashboard, add a highlighted section named:

**Trending This Month**

Suggested subtitle:

**Most in-demand tech skills chosen by learners this month.**

Keep this section near the top (after hero/banner) and limit to 6-8 cards.

## 2) Recommended trending categories (2026)

Prioritize these themes first:

1. Generative AI & Prompt Engineering
2. AI Agents & Automation Workflows
3. Data Analytics with Python + SQL
4. Cloud & DevOps (AWS, Docker, Kubernetes)
5. Fullstack Projects with React/Next.js + TypeScript
6. System Design + Interview Preparation
7. Cybersecurity Essentials
8. Career-focused job-ready tracks

## 3) Product ideas you can launch immediately

Use these as purchasable materials/course cards:

1. **GenAI Prompt Engineering Masterclass** (Intermediate)
2. **Build AI Agents with Python (Hands-on)** (Intermediate)
3. **Data Analytics Job Track: Python + SQL + Power BI** (Beginner to Intermediate)
4. **AWS + DevOps Accelerator** (Intermediate)
5. **Fullstack TypeScript Projects Bootcamp** (Intermediate)
6. **System Design for Product Companies** (Advanced)
7. **Cybersecurity Fundamentals for Developers** (Beginner)
8. **DSA + Interview Sprint (8 Weeks)** (Intermediate)

## 4) Conversion-optimized card format (for each material)

Every card/landing page should include:

- Clear outcome in title (`Build X`, `Crack Y`, `Master Z`)
- Skill level badge (Beginner/Intermediate/Advanced)
- Price and discount anchor (if running campaign)
- Social proof (rating, learner count, testimonials)
- Strong CTA: **Purchase & Start Learning**
- Limited-time trigger (cohort start date or bonus expiry)

## 5) Suggested launch workflow (weekly)

Repeat this every week:

1. Pick top 3 themes from learner demand
2. Publish/update 2-4 materials
3. Pin top 6-8 cards in "Trending This Month"
4. Send announcement via email/WhatsApp/Telegram
5. Track: views -> checkout -> purchases
6. Replace low-converting cards after 7 days

## 6) Pricing and bundle strategy

- Entry materials: low-ticket (for first purchase)
- Core job tracks: mid-ticket
- Premium cohort/project mentorship: high-ticket

Bundle examples:

- **AI Starter Pack**: Prompt + Python + Projects
- **Interview Cracker Pack**: DSA + System Design + Mock Interviews
- **Data Analyst Pack**: Excel + SQL + Python + Dashboarding

## 7) Content assets in this repository

- `content/study-materials.json`: your source catalog
- `scripts/update_trending.py`: automatic trend scoring script
- `content/trending-materials.json`: ranked trending output
- `snippets/trending-widget.html`: embeddable section (if custom frontend is used)

If your Graphy plan limits custom code blocks, use the ranked list manually to set "Featured/Trending" course order inside the dashboard each week.
